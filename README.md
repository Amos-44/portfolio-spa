# Portfolio SPA – React Project Showcase

A modern Single Page Application (SPA) built with React that allows users to add, search and manage projects dynamically. This application simulates a portfolio platform for a creative agency to showcase their work.

---

## Features

- Add new projects dynamically  
- Search projects by title, description or technologies  
- Delete projects  
- Data persistence using LocalStorage  
- Responsive design (mobile, tablet, desktop)  
- Built using reusable React components  

---

## State Management

State is managed in the App component using:

- useState – for projects and search input  
- useEffect – for saving data to LocalStorage  
- useCallback – for optimized functions  

---

## Tech Stack

- React (Vite)
- JavaScript (ES6+)
- Tailwind CSS
- HTML5

---

## Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:Amos-44/portfolio-spa.git
cd portfolio-spa
````

### 2. Install dependencies

```bash
npm install
```

### 3. Run the application

```bash
npm run dev
```

---

## Usage

* Click “Add Project” to open the form
* Fill in project details and submit
* Use the search bar to filter projects
* Click Delete to remove a project

---

## Responsive Design

The application adapts to different screen sizes using Tailwind CSS:

* Mobile – Single column layout
* Tablet – Two columns
* Desktop – Three columns
